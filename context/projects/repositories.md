## Shared Characteristics

Every repository reflects Kellogg's development philosophy:

- **Local-first:** No cloud dependencies for core functionality
- **Open source:** MIT license — "Do whatever you want with it"
- **Documented:** Architecture decisions, README files, inline documentation
- **Tested:** Cairn alone has 2,033+ tests; all projects have test suites
- **SQLite:** Standard persistence layer across Python projects (WAL mode)
- **Ollama:** Standard LLM runtime across AI projects (no cloud APIs)
